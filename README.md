# KO?SALAD

**A community website · A student-built project**

[Visit the live website →](https://kosalad-platform.vercel.app/)

## Overview

KO?SALAD brings together people with different talents. Visitors can discover members, explore community projects, and apply to join.

## Explore the website

| Section | Purpose |
| :--- | :--- |
| [Members](https://kosalad-platform.vercel.app/members) | Discover people and their profiles |
| [Projects](https://kosalad-platform.vercel.app/projects) | Explore work shared by the community |
| [How it works](https://kosalad-platform.vercel.app/about) | Understand the community |
| [Join](https://kosalad-platform.vercel.app/join) | Apply for membership |
| [Quality Rush](https://kosalad-platform.vercel.app/game) | Play the browser game |
